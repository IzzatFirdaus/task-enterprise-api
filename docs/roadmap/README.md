# Roadmap Scope Boundary

This directory marks future product areas without pretending that their implementation contracts exist today.

The current application has no approved schema, authorization model, or interaction contract for projects, teams, collaboration, task metadata, notifications, configurable workflows, or user task import/export. Their code directories and modules should be created only when a roadmap item is selected and its requirements are defined.

Current implementation sources of truth:

- [Product requirements](../../PRD.md)
- [Technical architecture](../../ARCHITECTURE.md)
- [Architecture essentials](../../ARCHITECTURE-ESSENTIALS.md)

This boundary is intentional: empty application modules would create misleading structure and encourage speculative feature logic.
